# Monitora APS · Itacarambi

Sistema de monitoramento da Atenção Primária à Saúde de Itacarambi (MG).

- Página: publicada via GitHub Pages (`index.html`).
- **Nenhum dado de paciente fica neste repositório.** O cadastro e as alterações ficam em armazenamento privado (Supabase), acessível apenas com login de usuários autorizados.
- Para liberar um novo usuário: incluir o e-mail na tabela `usuarios_autorizados` do projeto Supabase.
